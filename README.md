# 谁的猫

两个人抢一只猫的心的网页小游戏。你和对象各操作一个角色，在同一个房间里想办法让小猫靠近自己：摸头、喂小鱼干、挥逗猫棒、扔毛线球、放纸箱、撒猫薄荷，还能抢对方手里的道具。时间到时，猫会走向"猫心天平"更偏向的那个人；如果平分秋色，它会说"两个都不要，我去睡觉"。

小猫有自己的想法：每局喜好随机（用过一次道具才知道它这局喜不喜欢），会困、会生气、会被吵到、会突然满屋跑酷，还会从茶几底下钻过去。

## 两种玩法

- **开房间**：一人点"开房间"拿到 6 位房间号，另一人在自己手机上输入房间号加入，各用各的手机玩。房间号通过公共信令服务器配对，连上后两台手机点对点直连。
- **同一台设备**：一台手机横屏一人握一边，或竖屏平放在桌上面对面；电脑上玩家 1 用 WASD + F/G，玩家 2 用方向键 + K/L。

## 文件

- `index.html`：游戏本体（纯前端，无需安装）
- `netplay.js`：开房间联机模块（MQTT 信令 + WebRTC 直连）
